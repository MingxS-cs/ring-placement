# 泛化结果说明

这一版已完成你选择的“新位置、新方向、新距离”测试。保持戒指外径25毫米、内径20毫米、厚7毫米，轴承外径50毫米、内径40毫米、厚5毫米；两者水平放置。所有结果来自机械臂的接触物理仿真。

冻结的96个场景覆盖八个搬运方向，以及45–75、75–110、110–160毫米三个距离段，每个方向与距离组合有四个点位。新模型、直线路径、旧模型三种方案均成功96/96，全部288次尝试保留。训练示范的端点距离为66.2–201.1毫米，因此这项测试包含短距离外推和范围内的新组合。

手机视频提供真实戒指中心的近似二维运动。新模型只有12个学习系数，输入是搬运进度和起点到终点的方向，输出是相对直线路径的纵向、横向偏移。执行时使用仿真中已知的物体位置；抓取、抬升、夹爪开合和释放由几何程序控制。曲线执行每步最多2毫米，夹爪跟不上就暂停，并且完成整条曲线后才开始放下戒指。

模型确实改变了机械臂搬运路径：实际戒指轨迹的平均最大横向偏移为11.74毫米，直线方案为0.046毫米。但三种方案都成功，所以目前没有证据证明学习曲线提高了放置成功率。

此前封存的三条真人轨迹共有35个观测点，其中29个是中间点。模型选定并冻结后才读取这些标签；比较时排除完全一致的两个端点，按每条原始示范等权计算误差。

| 方案 | 中间点平均误差 |
|---|---:|
| 新模型V4 | 10.91毫米 |
| 直线方案 | 8.76毫米 |
| 旧模型V3 | 15.67毫米 |

新模型在三条轨迹上都比旧版好，但都没有胜过直线。±5和±8像素的各100次测量扰动也没有改变这一判断。权重和候选选择没有根据测试结果重新调整。这些轨迹仍来自同一段固定手机视频，端点曾用于早期开发，不属于独立新拍摄的数据。

可支持的结论是：当前混合控制器在所测位置、方向和距离范围内能够完成放置，新模型改善了旧版的轨迹预测。换相机、换背景、换物体尺寸、从新图像识别物体或真实机械臂运行的能力仍未验证。像素按轴承直径换算的轨迹也不是标定后的三维位姿。
