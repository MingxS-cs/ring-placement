# TinyVLA implementation plan

**Goal:** Existing real phone motion drives a small RGB/text-to-robot-action model and a source-isolated spatial generalization experiment.

**Architecture:** Learned dense vision and text-conditioned waypoint decoder; generic proprioceptive servo execution; physical environment has no oracle FSM. Preserve all historical V4 artifacts.

**Tech stack:** Python, PyTorch/CUDA, NumPy, MuJoCo, OpenCV, FFmpeg; no pretrained model download.
